# TlopChen 知识库

记录网络运维、RouterOS、GitHub 学习相关的一切。

## 怎么用

- **找东西**：右上角搜索框直接搜
- **写东西**：本地编辑 `docs/` 下的 Markdown 文件，`git push` 后网站自动更新（约 1 分钟）
- **加新页面**：在 `docs/` 下建 `.md` 文件，再到 `mkdocs.yml` 的 `nav:` 里登记
