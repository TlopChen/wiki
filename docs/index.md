# TlopChen 知识库

记录网络运维、RouterOS、架构演进与 GitHub 学习相关的一切。

## 怎么用

- **找东西**：右上角搜索框直接搜
- **写东西**：本地编辑 `docs/` 下的 Markdown 文件，`git push` 后网站自动更新（约 1 分钟）
- **加新页面**：在 `docs/` 下建 `.md` 文件，再到 `mkdocs.yml` 的 `nav:` 里登记
- **写复盘**：已验证的变更与故障写入复盘笔记，按日期、分类和标签自动归档

## 目录

- [复盘笔记](blog/index.md) —— 按时间保存故障定位、方案取舍、验证和回滚
- [网络运维](network/home-lab.md) —— 当前家庭网络架构、ROS 规则管线、隧道、DNS、坑手册
- [GitHub 学习](github/git-basics.md) —— Git 基础、Pages、Actions
